# PrivatB — прототип мобильного банка (PWA)

Фронтенд-прототип мобильного банковского приложения: биометрический вход, дашборд,
операции по карте, генерация PDF-выписки, локализация UA/EN, тёмная тема и офлайн-режим.
Серверной части нет — все данные статические.

## Запуск

Service worker и установка PWA требуют `http://localhost` или HTTPS — через `file://`
приложение откроется, но офлайн-кеш и установка на устройство работать не будут.

```bash
python3 -m http.server 4173
```

Затем откройте <http://localhost:4173>.

В Claude Code этот же сервер поднимается конфигурацией `.claude/launch.json` (имя `privatb`).

## Структура

```
index.html              разметка всех экранов + SVG-спрайт иконок
css/styles.css          токены, компоненты, анимации, тёмная тема
js/i18n.js              словари UA/EN, t(key, params), выбор языка в localStorage
js/format.js            деньги, даты, относительное время
js/data.js              статические данные: карта, продукты, 82 операции, уведомления
js/statement.js         генерация PDF-выписки (jsPDF)
js/app.js               роутинг между экранами, рендер, события
vendor/jspdf.umd.min.js jsPDF 2.5.2 (локально, без CDN)
vendor/fonts-ptsans.js  PT Sans Regular/Bold, сабсет Latin+Cyrillic, base64 для jsPDF
manifest.json           манифест PWA
sw.js                   service worker: precache + офлайн
icons/                  иконки приложения (192/512/maskable/apple-touch/favicon)
```

## Экраны

| Экран | Что делает |
| --- | --- |
| Вход | Пульсирующий отпечаток + круговой прогресс, 2 с → успех → загрузка |
| Загрузка | Спиннер, прогресс-бар, ~1,9 с → дашборд |
| Головна | Карта (кликабельна), быстрые действия, вклад и кредит, последние операции |
| Картка | Карта, действия, 82 операции по месяцам, кнопка «Виписка» |
| Продукти | Мои продукты + предложения (детские карты, ипотека, автокредит, страхование) |
| Сповіщення | Лента с непрочитанными, «Прочитати всі» |
| Ще | Профиль, безопасность, лимиты, язык, тёмная тема, поддержка, выход |

## PDF-выписка

`Statement.generate({ from, to })` — ISO-даты включительно; возвращает Promise и
скачивает файл. Периоды: последняя неделя, последний месяц, произвольный диапазон
(с валидацией: обе даты заданы, `from ≤ to`, `to` не в будущем).

Документ содержит шапку с реквизитами, блок клиента и счёта, полосу итогов,
таблицу «Дата / Опис операції / Сума / Валюта», итоговый блок с входящим и исходящим
остатком, постраничные колонтитулы и разбивку на страницы с повтором заголовка таблицы.

Кириллица в PDF работает за счёт встроенного сабсета PT Sans (SIL OFL 1.1) — jsPDF
со стандартными шрифтами кириллицу не отображает. Сабсет содержит Latin, кириллицу,
пунктуацию и знак гривны `₴`.

### Пометка «демо»

`js/statement.js`, константа `DEMO_MARK` в начале файла:

```js
var DEMO_MARK = {
  watermark: true,   // диагональная надпись ЗРАЗОК / SPECIMEN
  footerNote: true   // строка в колонтитуле каждой страницы
};
```

Выписка по вёрстке повторяет реальный банковский документ, поэтому каждая страница
помечена как образец. Флаги влияют только на эту пометку и ни на что в интерфейсе.

## Баланс и данные

Баланс карты статичен: **511 000,00 ₴**. Операции хранятся от новых к старым без
остатков — остаток после каждой операции вычисляется обратным ходом от 511 000,00,
поэтому самая свежая операция всегда оставляет счёт ровно на этой сумме. Входящий
остаток за любой период выводится из того же ряда.

История: 82 операции с 05.02.2026 по 02.08.2026. «Сегодня» для прототипа зафиксировано
в `DATA.today = '2026-08-02'`, чтобы относительные периоды совпадали с данными.

Суммы форматируются с пробелом-разделителем тысяч и запятой перед копейками
(`511 000,00 ₴`) в обоих языках.

## Локализация

Язык переключается кнопкой UA/EN (шапка, экран входа, раздел «Ще») и сохраняется в
`localStorage` под ключом `privatb.lang`. Тема — `privatb.theme`.
Статические строки помечены `data-i18n`, динамические рендерятся через `t(key, params)`.

## Обновление кеша

При изменении любого файла из `PRECACHE` поднимите версию в `sw.js`:

```js
var CACHE = 'privatb-v2';
```

Иначе браузер продолжит отдавать старую версию из кеша.
